# FDE Casebook｜FDE 实战案例库

**给要入行 FDE（Forward Deployed Engineer，前线部署工程师）的人：一座持续更新的真实案例拆解库。**

FDE 是 2025 年以来科技行业增长最快的岗位之一：OpenAI、Anthropic、Palantir 和国内大厂都在抢人，年包百万的新闻满天飞。但一个绕不开的问题是——**网上几乎找不到"一个 FDE 项目从头到尾是怎么走完的、每一步卡在哪"的真实拆解**。概念科普很多，现场实录很少。

这个仓库就补这一块：持续搜集真实的 FDE / 企业 AI 落地案例（官方工程博客、一手从业者自述、可信媒体深访），按统一的全流程 7 环节拆开，加上点评，给想入行、正在入行、或想理解企业 AI 落地的人当指南用。

> v0.1（2026-10-24）：首批 4 个案例上线，持续更新中。案例每天在搜集，宁缺毋滥——没有真实过程细节的，不收。

## 怎么读这个库

每个案例都按同一把尺子拆——**全流程 7 环节**：

1. **选场景**：怎么发现痛点、怎么判断值不值得做、ROI 怎么算
2. **摸现场**：进驻调研、摸清老系统/数据/人，预期与现实差在哪
3. **定方案**：最小闭环/样板间怎么定，POC 边界与验收标准
4. **数据与集成**：脏数据、系统不开放、权限与合规、接口之痛
5. **开发交付**：Agent/RAG/工具链选型、评估（evals）怎么做、效果不达标怎么调
6. **上线采用**：培训、用户习惯、组织阻力、没人用怎么办
7. **迭代扩单**：效果怎么度量、怎么续费/扩到其他部门、踩过的坑与复盘

**拆解纪律**：每个环节只写来源里真实讲到的；来源没讲的，明确标注「来源未披露」，绝不脑补。数字一律注明口径（官方口径/作者自报/媒体观察），未独立核验的会写明。案例的可迁移启示写在每篇末尾的「对入行者的启示」，点评结论写在 verdict 里：学 / 不学，为什么。
